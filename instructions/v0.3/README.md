# EMBER Ver.0.3 指示セット

## 目的
Ver.0.2で「一周遊べる」を達成した次は、**戦闘中にスキルを使えること**と**一周の中でビルドの戦い方が変わること**を最優先で検証する。仮素材のまま、必要なゲーム的な視覚フィードバックだけ追加する。

## 現在の基準
Ver.0.2実装ブランチ `feature/v0.2-roguelite-loop` のコミット `6b8be235bc9d13585bdfb22b42785212a9bd4556` を基準とする。2026-11-16時点で `main` はVer.0.1のため、**mainを実装ベースにしない**。変更予定のPRや最新コミットを確認し、既存の未コミット作業は上書きしない。

## Ver.0.3の実装境界
**実装する**: 戦闘開始時TP補充、戦闘単位の有限ラウンド回復プール、共通レベルと少数の成長選択、1周内に行動を変えるスキル強化、戦闘HUDの最低限の改善、詳細ログと比較テスト。
**実装しない**: 大規模な報酬・イベント追加、恒久育成、分岐マップ、正式イラスト、派手なアニメーション、独自UIフレームワーク。既存の4戦ループを再利用。

## 今回のゲームデザイン仮説
- ボス戦後半でも、各キャラにスキルを使用できる機会が適度に残る。
- 速攻と継続戦闘がどちらも合理的な選択になりうる。
- 成長選択後に、実際のコマンド選択や対象選びが変わる。
- プレイヤーが文章ログを読まなくても、いま誰が攻撃し何が起こったか分かる。
