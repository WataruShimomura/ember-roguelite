# EMBER Ver.0.2 ゲーム仕様

## 設計の原則
- 情報は原則公開。敵の行動・対象・推定効果、成功率と計算内訳を確認できる。
- 考える時間は無制限、操作と演出は軽快に。判断が戦局を変え、ビルドによって役割が変わる。
- 暗記不足による初見殺しではなく、公開情報を使った選択に難しさを置く。
- 速攻に自然な利点（敵の行動回数減少）はあるが、**全戦闘共通のターン経過強化や制限時間は付けない**。防御/反撃・継続戦闘も成立させる。

## 最小1ランの流れ
出撃準備 → 通常戦1 → 3択報酬 → 通常戦2 → 3択報酬 → 2択以上の有限イベント → 強敵戦 → 3択報酬 → ボス戦 → 冒険リザルト。
- すべての戦闘で全滅したら終了。クリア・敗北後に再挑戦可能。
- 敵編成/報酬はシード由来。短い周回でよく、恒久強化・図鑑・本編ストーリーは不要。
- 戦闘間でHP/TP/装備/アイテムを引き継ぐ。

## 基礎ステータスとTP
- 数値ステータスは `MAX_HP` / `POWER` / `SPEED` / `MAX_TP` の4つ。現在HP・現在TPは可変状態でありステータス定義ではない。
- 味方3人はそれぞれ個別TP。仮値：MAX_TP=5、出撃時CURRENT_TP=3。基礎値と初期値はキャラ別に変更可能。
- 戦闘開始で全回復しない。最大値が増えても現在値を勝手に補充せず、最大値が下がった場合だけ現在値をクランプする。蘇生は明示効果のみ。
- 戦闘中のバフ/デバフ・状態異常・予告・行動済みフラグは戦闘ごとにリセット。戦闘不能（HP=0）は持ち越す。
- 既存のSPEED固定順、手番時即時実行を維持する。

## コマンド
- 通常攻撃（TP消費0）、キャラ固有スキル2種類、所持消費アイテム。共通「防御」コマンドを廃止。
- 通常攻撃の無条件TP+1も廃止。スキルは**使用者本人のTP**から支払う。
- 個別スキルや装備に防御、反撃、バリア、牽制などの効果を持たせるのは可。
- アイテム使用は原則手番1回を消費。TP回復・HP回復アイテムは有限所持。
- TP=0でも通常攻撃で戦闘を進められる。無償で永遠にHP/TP回復できる仕組みは禁止。

## 回復・サステインの設計
- 回復原資は有限アイテム、イベント報酬、または敵に与えた有限の実ダメージ。
- HP/TP吸収はオーバーキルを除く実HP減少量を基準にする。
- 敵ごとに**low-water mark（その戦闘での最低到達HP）**を保持する。ダメージ後HPが過去の最低HPを下回った分のみ「新規削減HPクレジット」として吸収の基準にする。
- 例：敵HP 100→60 ならクレジット40、60→80回復→50 なら10、50→20なら30。回復してから同じHPを削っても二重計上しない。
- 同一ダメージに複数吸収効果があればクレジットを1回算定し、その値を全効果が参照する。効果ごとの丸めルールは明示してログに残す。
- HP回復スキルは有限TPを消費する。TP↔HP変換による正味無限増加、敵回復、召喚、蘇生との組合せをテストする。
- 戦闘を無意味に長引かせることを抑止するための共通時間ペナルティは設けない。戦闘成果との交換により回復を有限化する。

## 装備・報酬・イベント
- 装備は武器・防具カテゴリを強制せず、各キャラ2枠から開始。戦闘間で入手・交換。
- 初期テスト用に、①MAX_TP上昇 ②実ダメージHP吸収 ③実ダメージTP吸収 ④被ダメージ軽減/反撃 ⑤TP消費軽減 ⑥火傷・既存の効果を組み合わせられるようにする。
- 装備によって同キャラが異なる役割になるよう、数値のみではなく行動の価値を変える効果も含む。
- 各戦闘後はランダムな3択から1つを選択。装備、消費アイテム、限定回復を選択肢に含める。報酬の二重取得不可、候補は同一シード・同一入力列で再現。
- 所持アイテムは有限。仮に3枠、スタック仕様は簡潔に決めて文書化。
- イベントは少なくとも2択で、HP/TP回復や装備獲得に有限の対価と機会損失が生まれる。イベント選択の無限反復は禁止。

## 敵・戦闘と情報公開
- 通常戦2種、強敵、ボスに異なる戦術的特徴を持たせる。既存敵を再利用してよい。
- 敵行動/対象/推定ダメージ/状態効果と計算根拠を表示。強い予告攻撃には対処機会を与える。
- 予告と実行が一致する。対象死亡時の無予告な切替はしない。
- プレイヤーに防御コマンドを押させるだけの敵構成にしない。複数の回答があり得るようにする。

## UI・ログ
- 出撃、戦闘、報酬、装備変更、イベント、戦闘結果、冒険結果の画面が必要。
- HP/TPはキャラ別に表示。スキルのコスト不足、発生源ごとの計算内訳、残りアイテムを確認可能に。
- 戦闘ログは構造化されたイベント。冒険の結果には戦闘別のHP/TP推移・装備変遷・報酬選択・イベント・戦績・シードを保存。
- 仮素材でも機能すること。画像/フォント/BGMは表示定義から差替可能。

## 明確に範囲外
恒久強化、図鑑、完成素材、物理/魔法別攻撃力、防御力という基本ステータス、すべての敵への時間経過強化、複雑な分岐マップ、無償無制限の回復。
