# EMBER Combat Core v1 — 戦闘1回の核を作る

## 目的
長期周回全体を変える前に、**3人パーティ対2〜3体の敵で、予告・スキル選択・TP・装備が相互作用する「戦闘1回」**の面白さを検証する。過去のDesign Lab v1〜v3のような無制限の自由設計でも、Ver.0.3の小変更でもない。今回は人間側が基本仕様を明示し、Codexは実装・反例探索・限定バランス調整を担当する。

- 基点: `feature/v0.3-growth-tp` / `c21c5bc4d42ff83602d2f74bd4d5f18c1678eed5`
- 指示: `instructions/combat-core-v1`
- 実装: `feature/combat-core-v1`（同じ基点から作成済み）
- 過去の議論: `docs/v0.3/`、`experiment/design-lab-v1`、`design/design-lab-v2`、`design/design-lab-v3`
- 2026-11-18時点でmainはVer.0.1。mainからコードを始めず、既存PRのマージも行わない。

## 読む順序
1. [COMBAT_SPEC.md](COMBAT_SPEC.md) 人間が固定した戦闘の基本設計
2. [PROGRESSION_AND_DIFFICULTY.md](PROGRESSION_AND_DIFFICULTY.md) **追加必須**：成長と攻略難度
3. [TEST_AND_ITERATION.md](TEST_AND_ITERATION.md) 観測、反例、改善権限、合否
4. [CODEX_TASK.md](CODEX_TASK.md) 開発手順・成果物

## この版で固定する
3人の異なる役割、味方個別の中粒度TP（上限30を仮の基準）、各人6候補・持込4（通常攻撃は別枠）、敵の意図と対象の開示、個別手番の即時コマンド、スキルの役割分離、戦術を変える装備、固定状況からの再戦機能。共通防御コマンドを足さない。

## この版で変えてよい
技の威力、コスト、補助効果の強さ・期限、敵HP/威力/行動比率、TP供給量とマイルストーン、装備の発動閾値など。**基礎構造を勝手に別ゲームへ変更しない**。設計前提が問題を生む証拠が出た場合、まずレポートで改修提案し、人間の承認を待つ。

## 検証対象の拡大（追加必須）
**成長が機能し、初期状態のままではボスに安定して勝てないこと**を検証するため、独立した通常戦→強敵戦→ボスの最低3戦ルート、数値と戦術の両方の成長、無成長/成長あり対照を追加する。詳細はPROGRESSION_AND_DIFFICULTY.mdを優先する。これは本編の長い周回への統合を意味しない。

## 非対象
12戦本番ルート、恒久育成、ラン全体の正式報酬表、マップ、素材完成、派手な演出、オンライン、長期メタゲーム。既存の4戦フローを壊さず、独立した短い成長付き戦闘試作として起動する。

## 完了の意味
Godotで遊べること、TP/スキル/敵/装備のテスト、3つ以上の異なるビルドを用いた同一戦闘比較と、無成長/数値成長/戦術成長/通常成長のボス攻略比較、既知の支配戦術と未解決点を正直に報告すること。面白さの最終判定はユーザーが行う。
