# EMBER Combat Core v2：自然な戦術相互作用と遊べるUI

## 目的
Combat Core v1で成立した「成長なしではボスを安定攻略できず、育成によって攻略力が上がる」前進を保ちつつ、**開発者が用意した専用の解法を当てるゲーム**から、一般化したルールと各キャラの技/装備を組み合わせ、自分で攻略法を作るゲームへ進める。

今回の優先度：①UIが分かりゲームとして試せること、②ピンポイントメタを汎用ルールに置き換えること、③複数キャラをまたぐ火傷などのシナジー、④有限アイテムを中心としたHP管理、⑤獲得物を少しずつ組み合わせる成長、⑥前版よりも攻略に工夫を要するボス戦とビルド比較。いずれも完了条件として検査する。

## 原則
- 「技がある」ではなく「異なる場面で選ぶ理由がある」ことを確認する。
- 特定の敵の固有ギミックを解除する「専用鍵」スキル/装備を原則なくす。一般的な防御、構え、弱体、持続ダメージ、手番、予告等の共通ルールに働きかける。
- 新しいシナジーを作るために、そのギミックだけを使える敵や必須装備を作らない。
- 戦闘中の無限回復を抑えるために継戦戦術そのものを否定しない。有限な回復アイテム、軽減/予告操作、機会費用を設計する。
- UI品質は「余裕があれば」ではない。UIが理解できないことによるプレイテスト不能はFAIL。
- これらは設計固定の一部だが、数値・表示・個別技の細部は根拠を残してCodexが自律改善可能。

## 対象範囲
独立の3戦（通常→強敵→ボス）、3人パーティ、成長2機会、レベル数値強化、各人6候補/持込4、個別TP上限30を比較基準として継続。基本即時手番と公開予告は維持。自動プレイと手動の双方で評価する。本編4戦へ無断統合しない。
