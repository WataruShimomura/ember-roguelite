# EMBER Ver.0.2 実装報告

参照指示ブランチ: `instructions/v0.2`。参照コミット: **`c2921672a4679ecc9e5c9e439c98278b56960db8`**。
実装ベース: `main` / `9e8461baf2a2b1ab35ada23dd896638941671d65`。
実装ブランチ: `feature/v0.2-roguelite-loop`。指示ブランチ・mainは変更していません。

## 実装したプレイループ

出撃準備 → 通常戦 → 3択報酬 → 装備準備 → 通常戦 → 3択報酬 → 祭壇2択 → 装備準備 → 強敵 → 3択報酬 → 装備準備 → ボス → 冒険リザルト。途中全滅でも戦闘/冒険結果を表示し再挑戦できます。

個別TP、現在HP/TPの戦闘間引継ぎ、有限アイテム3種類、装備の取得/交換、用途別のシード、予告と計算内訳、吸収の有限化、反撃と連鎖停止、戦闘/冒険ログを接続しました。

## 主な変更と責務

| ファイル | 責務・変更 |
|---|---|
| `data/content.json` | MAX_TP、初期TP、10装備、3アイテム、編成候補、報酬プール、イベント、2プリセット |
| `data/visuals.json` | 新敵/装備/アイテムの表示定義。画像参照は従来と同じく表示専用 |
| `ContentCatalog` | 定義ロードと参照/効果種別/資源上限/編成/報酬/プリセットの検証 |
| `RunState` | ルート、ノード、HP/TP、装備・予備装備、アイテム、報酬候補、戦闘記録、履歴、revision |
| `RunManager` | 初期化、編成と報酬の用途別RNG、戦闘開始・終了の一度だけの取込、選択と装備交換、終了/集計 |
| `BattleState` | 個別TP、敵ごとのlow-water mark、持越値をコピーして戦闘局所状態を初期化 |
| `BattleEngine` | 既存の固定順・revision・フェーズ検証を維持。本人TP支払い、所有アイテム使用、全滅判定 |
| `ActionCalculator` | 状態コピー上でダメージ・吸収・反撃・個別コストを順に計算。実行と同じ効果リストを返す |
| `EffectResolver` | 計算リストを適用し実数量を記録。火傷も同じダメージ/クレジット処理を使用 |
| `EnemyIntentPolicy` | 定義の周期から予告を固定。既存方針を新敵へ再利用し、再生術士の交互回復を追加 |
| `ResultAggregator` | 既存のイベント由来の集計を再利用。RunManagerが戦闘ごとの集計を合算 |
| `ui/main.gd` | 小さな画面ルーター、素材、ポップアップ、保存。ゲームルールは持たない |
| `ui/view_base.gd` | 見た目と共通部品のみ |
| `ui/preparation_view.gd` | シード/初期装備/プリセット選択 |
| `ui/battle_view.gd` | 予告・個別HP/TP・3コマンド＋アイテム・予測・内訳・入力 |
| `ui/reward_view.gd` | 報酬3択/イベント2択 |
| `ui/camp_view.gd` | 所有装備のみ交換、次戦への移動 |
| `ui/results_view.gd` | 戦闘結果/冒険結果、HP/TP推移、当時の内訳・選択履歴 |
| `tests/*` | Ver.0.2のルールへ更新した回帰・悪用防止・通しプレイ・描画スモーク |

UIはスナップショットを読み、管理クラスへコマンドを渡すだけです。RunManagerが戦闘終了を一度だけ取り込みます。戦闘中の双方の資源は別オブジェクトで、毎フレームの双方向同期はありません。

## 仮数値と意図

| 項目 | 数値・根拠 |
|---|---|
| 個別TP | 全員MAX_TP=5・初期3。最初の技能選択と後続戦への温存を両立 |
| 吸収 | HP30%、TP6%。17ダメージならHP5/TP1、少量の継続/反撃では切捨てで効率低下 |
| 守護の石 | 被ダメージ×0.8、威力7反撃。被害を受ける価値を作りつつ無傷にはしない |
| 集中の符 | 有料コスト−1、最低1。無償回復/HP↔TPの無限循環を作らない |
| 蓄霊の器 | MAX_TP+3、現在値補充なし。報酬や吸収の貯蓄余地 |
| 捨身の刃 | POWER+5 / MAX_HP−10。瞬間火力と耐久の交換 |
| 牽制の構え | 従来の単体+2/敵POWER−3に自身×0.5軽減を追加。共通防御を戻さず応答手段を残す |
| 治療薬/霊薬/蘇生薬 | HP35 / TP3 / 明示蘇生HP25。初期2/1/1個、最大3/3/2個、3種類を各1スロット |
| 戦後小休息 | 生存者HP18/TP1。装備・アイテムを獲得する機会と交換 |
| 祭壇 | 生存者HP24/TP1、または全員HP10を払い聖杯取得（最低1HP） |
| 通常敵 | 術士HP50、盾兵HP75。4連戦の資源持越に合わせて旧単発戦から調整 |
| 再生術士 | HP60/POWER7、偶数RにHP14回復。low-water対策を実際の敵行動でも検証 |
| 強敵/ボス | HP145/230、POWER15/18。既存の準備→次R大技を使用し、複数の対処機会を維持 |

全体共通の経過ターン強化や時間制限は追加していません。

## 実測した2ビルド

シード42、毎回小休息と祭壇回復を選択。下記は自動入力による通しプレイです。全行動列と各戦前後のHP/TPは [build_runs.json](build_runs.json) に保存しています。

| ビルド | 各戦ラウンド | 総ラウンド | 最終HP 剣/魔/僧 | 最終TP 剣/魔/僧 |
|---|---|---:|---|---|
| 速攻 | 3 / 2 / 5 / 6 | 16 | 66 / 63 / 52 | 0 / 0 / 2 |
| 継戦 | 3 / 3 / 6 / 5 | 17 | 85 / 72 / 61 | 4 / 5 / 3 |

速攻は猛撃・火球に序盤TPを使い、後半は通常攻撃と僧侶の回復を併用。継戦は通常攻撃でHP/TPを吸収し、予告大技に牽制の構えを使いました。これは2つの入力方針の観測であり、最適戦術やバランスを証明する結果ではありません。

## 検証と残る確認

Godot 4.6で戦闘・周回549検証、描画UI23検証が成功。詳細は [TEST_REPORT.md](TEST_REPORT.md)。9画面のキャプチャを同梱しています。

仕様上の未確定事項は [DECISIONS.md](DECISIONS.md)。恒久強化・図鑑・分岐マップ・時間ペナルティは導入していません。召喚や敵蘇生の新規アクション自体は追加せず、未対応の効果種はロード検証で拒否します。敵回復や同一敵IDの復活を模擬してもクレジットが増えないことを検証しています。

途中セーブ/再開、Windows以外、配布用エクスポート、差し替え素材の実動作、人手での長時間プレイは未検証です。ユーザーの手動プレイで「小休息に偏らず装備を取りたいか」「吸収/反撃で待つ価値があるか」「TP温存が面白いか」を次に確認してください。
