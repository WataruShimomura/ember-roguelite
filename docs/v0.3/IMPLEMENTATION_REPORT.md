# EMBER Ver.0.3 実装報告

参照指示: `instructions/v0.3` / **`33122df11cb0e04332968c47a8515cef415542c8`**。
ベース: `feature/v0.2-roguelite-loop` / `6b8be235bc9d13585bdfb22b42785212a9bd4556`。
実装先: `feature/v0.3-growth-tp`。main・指示ブランチ・Ver.0.2のコード/報告は保持。

## 実装内容

既存4戦ループ、個別TP、有限アイテム、low-water markを使う吸収、固定順、敵予告、計算内訳を維持し、TP方式C・共通Lv・選択成長・戦闘HUDを追加しました。共通防御、XP、無条件の能力上昇、恒久育成、時間ペナルティはありません。

| 段階 | 動作 |
|---|---|
| 出撃 | Lv1、全員装備2枠 |
| 第1戦の通常報酬後 | Lv2、スキル変化3択を1つ選択。未選択では進行不可 |
| 第2戦の通常報酬後 | Lv3、確認操作で全員の空の3枠目を解放。その後に既存の祭壇 |
| 強敵の通常報酬後 | Lv4、パッシブ3択を1つ選択。その後にボス |

選択や解放はphaseとrevisionで一度だけ受理。新戦には成長IDのコピーを渡し、新ランではLv1・2枠・選択なしへ戻します。

## TP方式Cと仮値

`rules.tp_recovery = { enabled: true, entry: 2, pool: 4, round: 1 }`。

RunManagerが一度だけ受理する戦闘開始で、持越HP/TPを渡して開始補充分を計算層へ渡します。BattleEngineは生存者へ開始補充→キャラ別プール作成→R1開始の順で適用。R2以降の開始に、空きTP・残プール・回復速度の最小値だけ回復します。満タンではプールを消費せず、KO中は回復しません。

プール残量はBattleStateだけに置き、戦闘終了時に破棄イベントを記録して0へ。RunStateには現在TPだけを取り込みます。開始補充、自然回復、吸収、アイテムは実増加量と発生源を記録します。entry/pool/roundは別々に変更でき、C・開始のみ・プールのみ・OFFを比較できます。

仮値+2/4/+1は指示の初期案を採用しました。全回復にはせず、各人に最大6点の追加供給機会を設ける意図です。自然回復が余ったまま終わる場合もあり、最大量が毎戦必ず得られるわけではありません。

## 成長候補

| Lv | 候補 | 挙動 |
|---|---|---|
| 2 | 火球・延焼 | 魔術師の火球本体後、元対象が生存していれば、別の生存敵1体へ火傷60%。独立抽選、装備の火傷率補正は追加分には乗せない |
| 2 | 火球・爆ぜる残り火 | 火球前から対象に火傷があれば、先に消費し12威力の追加攻撃。その後に通常の火球と火傷抽選 |
| 2 | 剣士・守護の牽制 | 牽制の構えへ10威力の反撃を追加。次の自身の手番で解除。装備反撃と併用 |
| 3 | 全員3枠 | 新枠は空。装備付与なし。既存の所有数から装着 |
| 4 | 迎撃の号令 | 各味方がその戦闘で初めて実ダメージを与えた反撃時、本人TP+1。満タンでも権利消費 |
| 4 | 残火の追撃 | 各味方がその戦闘で初めて行動前から火傷中の敵へ本体攻撃すると威力+8。継続ダメージ・反撃には付かない |
| 4 | 慎重な進軍 | 次戦以降の開始補充+1。直接の火力増強なし |

守護の牽制は指示で許可された「指定味方を守る代わりの反撃強化」を採用しました。追加対象選択を増やさず、既存の防御/反撃装備と役割が変わる構成です。

## UIの範囲

味方を左、敵を右へ配置し、現在手番は金枠、選択対象は青枠。HPは緑ゲージ、TPは青ゲージ、自然残量は独立した数値です。ダメージ・回復・TP・反撃・成長を表示定義の色で識別し、変化表示のための空間をあらかじめ確保しました。

短い静止ハイライトを使用し、タイマー・Tween・強制待ちは追加していません。強調表示はON/OFF可能。通常HUDで実行ボタンと直近の変化が画面内に収まることをテストし、スクリーンショットで確認しました。多数の効果は計算内訳から確認できます。

## 検証・結果

最終 `Test.ps1 -Render`: 回帰549、TP/成長67、比較74、描画UI37、失敗0。比較8ランともクリア。

速攻ルートのボス通常攻撃率はCで18.2%・技能9回、OFFで68.8%・技能5回。継戦ルートはCで27.3%・技能8回、OFFで50.0%・技能6回。Cのボスでは爆ぜる残り火1回/残火の追撃3回、継戦の牽制強化3回/号令2回が記録されました。

全32戦の開始/終了TP・補充/自然回復/吸収/消費・HP・行動回数・ボスTP時系列は [COMPARISON_RESULTS.md](COMPARISON_RESULTS.md)、元データは [comparisons.json](comparisons.json)。楽しさや最適戦術を証明する測定ではありません。

残る調整課題: シード42では開始補充のみでもCと同じボスR数でした。Cの供給過多や温存判断の薄れを手動で検証する必要があります。速攻のLv2強化はこの自動入力では通常2戦目に発動せず、ボスで発動しました。成長を早期に試したくなるかも評価対象です。

プールも有限アイテムも尽きれば、通常攻撃しか使えない場合は残ります。Windows以外、独立エクスポート、任意素材、人手の長時間プレイは未検証。詳細は [TEST_REPORT.md](TEST_REPORT.md)。
