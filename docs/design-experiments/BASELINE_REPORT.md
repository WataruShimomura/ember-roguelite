- **TPの供給。** 基本の上限は個人5、初期TP3、戦闘開始+2。R2以降は不足分に最大1、個人のプールを最大4まで使う。小休息・祭壇・霊薬・装備吸収も別にある。基準では回復量自体に余裕があり、83%以上の手番で満タン。専用の温存方針でも余剰が見られる。
- **遅延の利益と費用。** シード42・速攻装備・第1戦では、条件評価のR2終了・自然TP2・終了TP計12に対し、遅延はR5終了・自然TP5・終了TP計15。ただし霊薬1・治療薬2を消費し、ラン終了TPはいずれも15。全20ペアのラン終了TPは同値で、遅延は平均3.5ラウンド増。局所的な資源差は再現したが、全体で得をする待機戦法はこの条件で確認できなかった。
- **スキルの重なり。** 猛撃は通常攻撃と同対象・同種のダメージでPOWER+8、集中装備によりTP2→1。満タンが続くと、オーバーキルや別の効果が必要な場面以外は支払う動機が強い。火球はPOWER+5と60%火傷が同居し、火傷が不要な撃破圏でも直接火力で選ばれる。火炎波・牽制・ヒールには範囲・予告対応・回復という固有の役割がある。
- **装備の効果。** 反撃・吸収・行動順補正にはすでに戦術差がある。例えば反撃で敵を倒す選択は既存ルールでも成立する。一方、指輪のPOWER+3や火傷率+15ポイントの装備は、装着だけでは選べる操作を増やさない。第3戦で装備枠を増やす運用では、初回報酬の価値が出るまでに1戦を挟む。第3サイクルで固定の指輪報酬に対する行動差を比較した。

## 条件と再現

シード42〜51 × 2プリセット × 7方針を各条件で揃えた。通常試行は既存の敵編成・4戦・初期HP/TP・アイテム。成長は速攻装備が「爆ぜる残り火／残火の追撃」、継戦装備が「守護の牽制／迎撃の号令」。初回報酬は装備、その後は小休息、祭壇は回復。Lv3の空き第3枠を使える時点で剣士に装備する。

| 方針 | 主な判断 |
|---|---|
| rush | 即時打点と敵手番を消す撃破を優先 |
| reserve | 残り戦数に応じてTP支払いを重く評価 |
| delay | ボス以外で残り1体になってから最大4ラウンド、敵を残す合法手を優先 |
| defense | 予告に対する軽減、反撃、回復を高く評価 |
| synergy | 火傷や回復・吸収などの付加効果を高く評価 |
| conditional | HP、予告、TP、残り戦数から選択 |
| random | 専用乱数で合法なスキル・対象（所持アイテムも含む）から選択 |

ヘッドレスの全実行は [EXPERIMENTS.md](EXPERIMENTS.md) のコマンドで再現できる。方針の重み・同点順は [design_lab_policy.gd](../../tests/design_lab_policy.gd)、基準のラウンド・資源・装備・成長は [METRICS.json](METRICS.json) に収録した。
