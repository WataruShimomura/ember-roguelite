# EMBER Design Lab v1 — レビュー判断

| 候補 | 判定 | 根拠 |
|---|---|---|
| ラウンド自然TPを外し開始補充を残す | 採用推奨 | 満タン率を84.0%から42.7%へ下げ、遅延による自然TP加算を直接解消。長期戦のTP枯渇は人手で確認する。 |
| 鎧割りと火種の同時導入 | 保留 | 構えへの対抗手段は成立。通常攻撃率53.2%、総被害約24%増。鎧割りと火種を個別に検証する。 |
| 味方の次手番まで守る護符指輪 | 却下 | 実際に被害を軽減したが、意図した防御方針で選ばれず、剣士の牽制と競合。現在の持続と手番コストの組み合わせでは報酬として弱い。 |

「採用推奨」はレビューに進める候補を指す。試作は独立した起動モードで試せる。 [全条件・再実行方法](EXPERIMENTS.md)

## 人間が確認する順序

1. **TPを使う判断。** 通常版と `--lab=tp` のシード42を比較し、継戦構成の終盤で攻撃・回復のためにTPを温存する手応えを確認する。第1戦を引き延ばす利得と、霊薬・治療薬を使う損失を一緒に見る。
2. **盾兵を残す順序。** `--lab=skills` の第1・第3戦で、構え中の盾兵への鎧割りと、無料の通常攻撃で足りる撃破圏を比べる。火種は敵が手番前に落ちる局面と、火傷まで生き残る局面で判断が変わるかを確認する。
3. **報酬と装備枠の価値。** `--lab=gear` ではランダム報酬から入手するか、準備画面で「護り手の指輪」を選んで護符を試す。最奥の全体予告で、遅い味方を守る手と牽制や撃破を比べる。次の試作は、行動の機会費用を下げつつ既存の予告対応と競合しにくい効果を1種類だけ比較する。

4戦すべてをクリアできるか、平均被害を下げられるか、選択が面白いかは別の問い。今回の自動プレイは固定シード・固定方針での比較であり、報酬に対する人間の選好、長い本番ラン、最適攻略は未検証。 [比較データ](METRICS.json)
