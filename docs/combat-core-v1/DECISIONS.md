# Combat Core v1 — 設計判断

基点 c21c5bc4d42ff83602d2f74bd4d5f18c1678eed5。指示初版 110e26c38c6236482379e8fc242c3ce9400e09e0、更新 37ae0259ef66118069c2c2957db64af16b67838d。旧4戦とは分離し、通常・強敵・ボスの専用ルートを用意する。

| 固有技 | 選びたい局面 | 温存・別手がよい局面 |
|---|---|---|
| 連斬 | 通常との打点差で敵の手番前に撃破 | 無料で同じ撃破、または次の断唱用に残す |
| 破甲 | 盾を外し物理を詠唱士へ通す | 構えのない相手、通常で即撃破 |
| 断唱 | 撃破圏外の致死大技 | 大技なし、再詠唱で中断無効、無料減衰で十分 |
| 挑発 | 剣士が引き取れば後衛が生存 | 剣士低HP、全体攻撃、既に剣士狙い |
| 返し刃 | 剣士への確定打を受けながら返す | 狙われない、先に倒せる |
| 連携撃 | 標的を使って大技前に撃破 | 標的なし、盾が実際の着弾先になる |
| 火印 | 次の剣士への準備。導火で火傷も用意 | 連携前に決着、火傷だけなら炎弾 |
| 炎弾 | 長生きする敵に火傷2回 | 瀕死の敵、既に火傷があり次に爆ぜ火を使いたい |
| 爆ぜ火 | 燃焼を待つより大技前の撃破を優先 | 火傷なし、継続で足りる |
| 火炎波 | 複数敵の閾値を進める | 1体の残HP調整、単体撃破を急ぐ |
| 減衰 | 低TPでも予告に対応して生存線を越す | 攻撃予告なし、撃破で済む |
| 魔力転換 | 傷を戻し火傷中の攻撃元を抑える | HP満タン、先に複数敵を処理できる |
| 槍撃 | 衛士狙いの相手を先行撃破 | 通常で倒せる、対象が他人 |
| 庇護 | 当人が耐えられない攻撃を衛士へ | 衛士低HP、全体攻撃、分散で生存可 |
| 分散 | 単体の致死線を2人の余力に再配分 | 2人とも低HP、総被害を減らす必要 |
| 迎撃 | 高火力が衛士に来る、返礼の次撃を使う | 狙われない、撃破で済む |
| 応急 | 次の攻撃までに大きな欠損を戻す | 回復なしで勝てるなら戦間の同一使用枠へ |
| 結束 | 次の味方の手と標的を組み、複数手で価値を取る | 味方が手番前にKO、敵が瀕死 |

減衰と分散は初期仮値4から0TPへ変更。減衰は打点なし、分散は総被害を減らさない。TP0でも2種類の対応を残す。装備は各人2種、1枠。迅撃による並び替えの代わりに挑発と標的を結ぶ誘刃を採用し、SPEED順を固定する。

治療技は各戦・各技1回。残っている応急・魔力転換と初期傷薬は戦間にも同じ支払いで使える。戦後だけの回復報酬や入場補充は導入しない。次戦の開始時に戦闘用の使用権のみ初期化する。瀕死敵を残して治療する利益を、即撃破して同じ治療を行う対照と比べる。
