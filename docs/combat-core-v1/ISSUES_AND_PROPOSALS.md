# 改善履歴とレビュー観点

## 初期校正と改善1回

初期校正では3シード×3攻略方針で無成長9/9勝。防護を持たせ、標的・火傷・反撃による弱点を作り、灰の波の被害を弱点利用で変えた。初期校正の最終点はコミット `7e13c0d`。この時点で主比較はU0 0/60、U1 17/60、U3 126/180。継戦だけ17/60と低かった。

**改善1回目** `f30eff8`。残り火傷1回の盾を爆ぜ火で倒すと、伝播先の火傷はその周期末に失効し、次の魔術師が使えないことがあった。伝播時だけ残り+1、上限2にした。同じシード・方針の継戦は17→30勝／60、平均終了HP31.95→45.72、爆ぜ火によるボス防護解除17→20回。他の成長系統やU0/U1の勝数は変化なし。副作用は、2体が残る局面で手袋による燃焼が最大1回増えること。単独ボスへ伝播する先がなく、依然として不発。2回目の調整は実施していない。
