### 方針の限界

各手で合法な候補を実行し、次の入力までの実結果と現在の敵予告から評価。被害、KO、撃破、TP、状態、反撃の重みを方針ごとに変えた。長い連携を探索する最適プレイヤーではない。遅延は最後の敵が25%以下で最大9味方手を使う。ランダムは同一シードで合法手だけ選ぶ。これら2つは主比較と区別した。実行コードは [policy.gd](../../combat_core_v1/policy.gd)。
