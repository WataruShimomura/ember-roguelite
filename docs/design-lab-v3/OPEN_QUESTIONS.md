# 人間レビューで決めること

1. **手順を組む面白さと入力負担の釣り合い。** S1で「全員を自由な順で並べる」Aと「各技が前か後かで決まる」Bを比べる。予告が複数ある場合、どちらなら自分で見つけた別解を説明できるか。操作回数に加え、予告を見てから方針を決めるまでの時間と、入力のやり直しを観察する。
2. **何を次戦に残すと納得できるか。** 12戦で隊が融通できるQと、用途の決まった札をそれぞれ比較する。終盤まで持ち越しても毎回余る、または一度の誤った支払いで固定枯渇する場合、回復を増やす前に切り札と予告の組合せを見直す。少なくとも「使う理由」と「使わない理由」が2つずつ自分の言葉で挙がるかを見る。
3. **報酬で失う技を選べるか。** 同じ次戦を標準・X・Yで試し、誰が先に入力し、誰が被害を受けるかを比較する。Xを選んだ後に元の妨害を恋しく思う局面や、Yを外して傷薬を残す局面があるか。両方を併用可能なBでは、無条件にX＋Yが最良にならないかも確認する。

Cを再審査する条件は、弱い敵からの一撃払い戻しを減らしても、枯渇時に防御と攻撃が残ること。初期火勢で装備の即時性を補う案は、新たな開幕一択を生まないか別途審査する。

レビュー用の比較順はAとBの初回プレイ順を参加者間で入れ替える。同じスナップショット、予告の解決時点、残HPと残資源を使う。今回の判定は机上であり、面白さ、意思決定時間、12戦の疲労は未確認。 [次段階の仕様](NEXT_PROTOTYPE_SPEC.md)
