# Ver.0.3・Design Lab v1/v2から残った問題

| 参照した結果 | 構造的な原因と効かなかった修正 | v3の問い |
|---|---|---|
| Ver.0.3は個人TP上限5。開始+2、R2以降毎R最大1、個人プール4。固有技2つと通常攻撃で、集中装備は有料技を最低1まで軽減。 | 1の差が大きく、装備によるコスト低下が行動の種類より使用頻度を変えた。予告と固定順では、遅い味方が役に立つ前に解決する場合がある。 | 共通の予算、用途別の札、戦闘限りの成果報酬という異なる配分で比較する。 |
| v1では満タン手番84.0%→42.7%。長期戦のTP0手番は10/473→134/524。 | 量の修正で温存が効くようになったが、枯渇したときの行動を増やさなかった。瀕死敵を残す局所的な自然TP差は観測された一方、基準20ペアのラン終了TP差は0。遅延最適が確認されたと広げない。 | 供給は戦闘外または根拠のある有限成果に限定。無料技だけで解ける戦術と解けないものを示す。 |
| v1の鎧割り＋火種では通常攻撃率38.0%→53.2%。護符は固定報酬で110回使われ、遅延・ランダムに限定。 | 役割を狭くするだけでは、条件のない戦闘で枠が余る。防御コマンドは予告に合っても、牽制と比べた1手の機会費用が大きかった。2技同時変更のため個別寄与は未分離。 | 無料・固有・報酬技の比較で、対象と後続を動かし、重複する手は統合する。 |
| v2の一括で刻印228・追撃222（標準の次戦）、返し槍ありの次戦勝利20/50対40/50。 | 順序を選べても、連携相手を固定すると同じ手順が合理的になりやすい。槍撃を外して術後の反撃へ賭ける費用が大きい。 | 印を必須にしない撃破と対応を個別に用意し、同じ報酬が得にも損にもなる局面を並べる。 |
| v2のタイムラインでは硬直で追加手を作れた。通常装備・状況判断は印計5.4を残した。 | 局所の時間で解けるなら、携行資源を使う理由が薄い。短いホライズンは、発動前に測定を打ち切ると被害回避に見えてしまう。 | 累積待ち時間を基準にせず、共通の敵予告が解決した後まで比較する。札の用途と補給で実際に迷うかを問う。 |

v1の実験範囲は、同じ4戦・成長・入力で局所差を追うことが中心だった。既存の戦術語彙が固定された理由の一つは、公平な比較のために敵、UI、TPと技の構造を共有したこと。v2でこの制約を外したが、共通する敵・効果と2戦の規模では、報酬から次の資源選択までの長い因果はまだ読めない。今回は実装差分や勝率を評価軸にせず、支配戦術と長期収支を文書で先に反証する。 [Ver.0.3の仮定](../v0.3/DECISIONS.md) · [v1の集計](https://github.com/WataruShimomura/ember-roguelite/blob/08da9822099ed9a9a42cc02421ee42f5677860d6/docs/design-experiments/EXPERIMENTS.md) · [v2の試作結果](../design-lab-v2/PROTOTYPE_REPORT.md)
