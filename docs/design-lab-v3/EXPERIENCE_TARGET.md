## プレイヤーが繰り返す判断

1. **敵の意図を読む。** 「術師HP30へ36」が出たら、発動前に撃破、予告を止める、他の味方で肩代わりする、の結果が見える。HPが多い味方に移して次戦に備えるか、希少資源を払って全員のHPを残すかを選ぶ。
2. **味方3人の仕事を組み直す。** 同じ敵でも盾の有効期間や術師の残HPによって、盾を割る、詠唱士へ届かせる、姿勢を作る、連携を完遂する、の優先が変わる。ゼロ資源でも予告と対象を読む価値がある。
3. **次戦の余力を見積もる。** 今の被害、次戦のHPと資源、回復・補給の入手機会を照らし合わせる。瀕死敵を残して回復だけを繰り返すと有利になる仕組みは外す。敵を倒しきる前に有限アイテムを使えるかどうかも検証する。
4. **報酬で次の入力が変わる。** 早い撃破を成立させる報酬、被害を引き受けて反撃する報酬、何も交換せず補給を得る選択を同じ次戦で比較する。入手直後から操作が変わり、装備した技が効きにくい敵では元の技を残しておく価値がある。

## 観察したいこと

| 局面 | 確認する行動 |
|---|---|
| 初見の緊急予告 | どの技が誰を救い、何を消費するか、画面を見て説明できる |
| 同じビルドのHP・資源違い | 支払う場面と温存する場面がそれぞれ2つ以上あり、理由が異なる |
| 枯渇後のボス | 予告対処と撃破手順の両方に意味があり、低コストの1手に固定されない |
| 報酬取得直後 | 資源を含む同一の戦闘開始状態で、初手・対象・後続のうち少なくとも1つが変わる |
| 12戦の想定 | 繰り返しの入力数、補給頻度と枯渇を見通せる。装備枠は膨張しない |

思考時間は無制限。表示は、対象つき予告、優先順、結果と消費、次の補給の順で見る。明確な期限のない強制演出は設けない。楽しさ・理解時間・繰り返しの負担は人間の比較プレイで判断する。 [反証局面](SCENARIO_WALKTHROUGHS.md)
