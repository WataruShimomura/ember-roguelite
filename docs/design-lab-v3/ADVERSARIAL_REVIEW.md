# 支配戦術と資源の反証

以下は机上の反例。比較の前に「同じ味方が生存し、同じ敵行動まで進み、次戦へ持ち越せる状態か」を揃える。HP、持越資源、アイテム、残敵、手数を独立に比較する。

## 収支を壊す入力

| 攻め方 | A 共有補給 | B 戦術札 | C 火勢 |
|---|---|---|---|
| 瀕死敵を残す／弱攻撃のみ | 戦闘中の補給収入0。HP・傷薬・補給は増えず、同じ戦後治療が即決にも使える。 | 待機や使わなかった札は新たな札を生まない。後手が撃破より遅い場合も傷薬は戦間で使える。 | 既に消費した閾値は0。戦闘内治療を許す旧案ではHPを持ち越せて利益が出た。治療を戦間へ移す修正が必要だった。 |
| HPを支払って資源を得る | 変換を定義しない。HPを使うのは肩代わり先としてだけ。 | 被弾時の反撃や割引から札は発生しない。 | 反撃で初めて境界を跨ぐとHは出るが、戦闘限り。自傷でHを得る規則はない。 |
| 敵回復を反復利用 | 固定の戦間キャンプのみ補給。敵自体が何度回復してもQは変わらない。 | 同じ敵への落雷や護札の使用で所持数は減るだけ。 | 初回しか獲得しない。例として最大60の敵が46→44で+2、44→58回復→44再削減は+0。25%も別の一度限り。 |
| 召喚・蘇生 | 初期範囲外。将来の報酬はユニット撃破と結合しない。 | 初期範囲外。蘇生は札を再初期化せずに同じ所持枠を使う。敵防御を繰り返し踏んでもキャンプは再発行されない。 | 追加敵は境界権利0。既存敵の蘇生は元IDの消費済み境界を維持。復活のたびに別IDで生成すると上限の再利用が可能なので、発行権を初期敵IDに結び付ける。 |
| 敵を残したまま状態を準備 | 有利な印・反撃準備は持越しない。最終全滅が勝ち扱いになったり、死亡直後の反撃が戦後収入を発火したりしない。 | 結界の次回弱体化は戦闘限り。味方の持越HPと傷薬は準備の繰り返しで改善しない。 | 火勢、切目、予約中の弱体化は戦闘終了で失効。初期火勢を報酬が増やす変更には、開幕の違いと閾値到達の自己増殖を別に審査する。 |

A/Bで補給は固定チェックポイントごとに一度。資格は戦数を進めて該当キャンプに到達したこと。再戦・キャンプ再入場・同じ報酬画面への戻りで再発行しない。Cでは出現敵数を増やすと通常発行量が増えるので、追加戦闘・召喚を導入する場合は初期敵の合計閾値も再審査する。

## 強すぎる手と、弱くなりすぎる手

- **Aの無料肩入れ＋凪。** 予告36を23まで下げて剣士が受ける。魔術師HPが低く、剣士だけ潤沢な編成が続けば断唱を温存する方が安い。連続単体予告で剣士HP22・術師HP30に達すると同じ手は剣士を倒す。後段の予告と対象が違う状況でも比較する。無料技に一律クールダウンを足すと選択が減るため、先に「凪」の軽減と対象、複数予告の頻度を変えて対照化する。
- **Aの導線→符弾。** HP37の敵を38で先殺しして無料3手より明確に強い。警護中は導線が盾に移り、術師はマークを使い切るか詠唱士へ素の8を通すかを選ぶ。高HPの敵に対して6Qの断唱を失う費用が働く。いつも警護なし・HP27〜38であれば同じ初手が支配する。1回消費、同周期、同対象とし、重ね掛けや別敵へのコピーを外す。
- **Bの速刺と重断。** 予告が毎回致死なら、前手で足りるときだけ速刺、足りないときは札に固定されうる。予告の弱い周期には後手16が前手6を上回る。逆に被害の小さい戦闘ばかりなら重断＋後続が常勝する。敵HP12のS2急、盾HP17の猶予、S3の衛士24致死を別々に置き、前手／後手が入れ替わるかを確認する。
- **Bの仕込み。** 標準装備で魔術師自身が仕込みと残光を同周期に選べず、仕込みだけを持つ実用性が薄い。剣士が追刃を装備する場合だけ組合せとして表示し、単独では持込候補から外す。残光も味方による印の供給がない標準では閃光8に対して5の後手なので劣後する。次試作ではこの死に枠を削り、後手の選択は剣士の重断に集約する。候補のための候補を増やさない。
- **Bの札の偏り。** 雷のないS1で衛士HP21なら護札でも22を受けて倒れる。両札を共通プール化するとAに近くなり、「何を持ってきたか」の検証を失う。直近の敵予告種別と次補給を公開し、誤った札の構成で常に詰むなら、厳しい予告の頻度を見直す。XとYを同時装備できるが、雷札は予告取消に使えず、楯札は衛士への引受けに使えない。両方同時装備の退路の狭さは未評価。
- **Cの閾走。** 弱敵を資源源にすることで+4が3支払いを上回り、S5の小型敵を優先する手を強くする。傷薬の移行でS4を解決してもこの問題は残る。候補修正は「有料行動で越した境界も消費するが、発行しない」、または「各敵の2境界を1つに統合」。前者は強い技が資源機会を奪い、後者は枯渇しやすい。両方を未検証で重ねず、今回はCを見送る。

一択を判断する際は、同じ比較状態で被害を受ける人、減る札の種類、残敵を固定した上で、予告が解決した時点を揃える。S3のボスやS6の議論を開幕の勝率だけへ還元しない。 [局面と数値](SCENARIO_WALKTHROUGHS.md)
