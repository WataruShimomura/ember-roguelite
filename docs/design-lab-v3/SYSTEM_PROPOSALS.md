# 資源の出どころが異なる3案

## 共通の審査条件

3人の上限HPは各100、初期は満タン。S1では80／30／60。盾兵の構えは物理を半減し端数切捨て。術式は明記した倍率のみ適用。詠唱士は魔術師へ単体36を予告、次の周期は自身を最大14回復（1戦1回）、以後は同じ予告を繰り返す。盾兵は構えと単体14を交互。ボス比較はHP100、周期ごとの単体36と24。例外の警護・対象・時刻は各シナリオに記載。予告対象が先に倒れた攻撃は空振りし、標的を変える効果は表示される。ダメージ、資源、HPは整数。反撃は発生した被害1件につき最大1回、反撃からの再反撃はなし。

傷薬は初期1・所持上限2・1個で生存者1人のHP+18。**戦間でのみ使用可能**。HPと傷薬は持越、マーク・構え・燃焼・反撃の予約は戦闘終了時に消える。蘇生手段、無限召喚、戦闘中の無費用回復、全員共通の防御は初期案から除外。将来の蘇生・召喚が関わる制約は反証資料に記載した。12戦モデルでは第2・5・8・11戦後に報酬、第3・6・9戦後に固定キャンプ。報酬は各案のX、Y、または交換せず傷薬1個。初回報酬を取れば次戦から交換可。各案とも一人に装備1枠、装備で持込技を置換しても枠数は増えない。同じ報酬の重複は禁止。POWER単独増加や装備枠追加は報酬に入れない。学習は成功条件が異なる別技を解放する。

## A — 戦間補給・隊で融通する共有予算

味方1人1手を好きな順に置き、全員確定、味方の手→敵の公開順。予測は同じ順で被害、対象変更、空振りを計算。予約時点の補給だけで支払いを保証する。対象が解決途中で消えた未実行手は失効し、支払わない。隊で補給点（以下Q）を共有し、**初期12／上限24**。キャンプで+8、上限超過分は失う。敵撃破・削減HP・待機による補給は0。補給アイテムとコスト割引は外す。資源・HPは戦間持越。

| 人物 | 候補と持込例 |
|---|---|
| 剣士／通常候補6から4 | **突進**0Q・物理10（打点）、**盾裂**0Q・術式扱いの4＋構え解除（前衛突破）、**断唱**6Q・ダメージなしで大技を消す／大技以外の攻撃は−4（予告妨害）、**肩入れ**0Q・味方への次の単体攻撃を剣士へ移し8軽減（引受け）、狙撃0Q・物理7で警護を無視（後衛処理）、裂傷2Q・物理3＋R末に5を2回（継続圧力）。初期は太字4。 |
| 魔術師／通常候補4から3 | **符弾**0Q・術式8、**火印**0Q・術式4＋R末に5を2回、**凪**0Q・選んだ攻撃予告−5、散符4Q・敵2体へ術式8。火印は再使用で残り回数を2に戻すだけ。 |
| 衛士／通常候補4から3 | **槍**0Q・物理8、**分散**0Q・指定味方への次の単体攻撃を衛士と均等分割、奇数の端数は衛士、**反撃**0Q・次回被弾後、生存なら9を返す、楯崩2Q・物理5＋構え解除。 |

肩入れと分散は同じ一撃に両立せず、先に予約した効果を優先。持続は現在ラウンドの敵行動終了まで。予告が構え・回復だった場合は対象変更効果なし。力押しと防御、即時と継続の用途を一人の候補内でも分ける。候補解放の想定は最初の報酬選択で剣士の狙撃／裂傷、次で術師・衛士の第4候補。持込変更は区間の次敵情報を見て戦間のみ。

| 報酬 | 技・代価 |
|---|---|
| X 導線の刃 | 剣士の断唱を**導線**に交換。4Q・物理10。実際に命中し生存した相手への次の符弾だけ同ラウンド中に8→20、1回で消費。警護で移った場合は実際に当たった敵に付与。断唱による後衛の直接妨害を失う。 |
| Y 返礼の楯 | 剣士の断唱を**返礼**に交換。3Q・味方への次の単体攻撃を剣士へ移し10軽減、生存して被害を受ければ攻撃元へ12反撃。無料の肩入れと同じ空間を使うので、一撃に両立しない。 |

**成長経路。** 速攻は序盤に盾裂から符弾を通し、中盤の導線で詠唱士先殺し、終盤の盾だらけの区間で狙撃を持ち込み断唱へ戻す選択も取る。継戦は序盤に肩入れと分散をHPの余る人へ割振り、中盤で返礼を取り反撃で後続の撃破を変え、終盤に剣士が低HPなら返礼を外し傷薬を優先する。単純な上乗せで毎敵へ導線を押せないよう、一方は妨害枠を失い、もう一方は剣士HPを使う。

**同じ標準ロードアウトでの4判断。** ①術師HP30に36、剣士HP20・衛士HP15・敵は撃破圏外。凪で31まで減らしても肩入れ後23は剣士を倒し、分散の衛士側16も致死なので断唱6Qを使う。②同じ予告で、衛士が同周期後段に別の14を受けるHP28、剣士HP22。凪との併用でも分散後の衛士残12や肩入れ後23では犠牲が出る。断唱6Qなら衛士は14残る。③警護のない敵HP13なら剣士10＋魔術師8で予告前に撃破し6Qを温存。④術師HP65で単体36、次戦は強敵、剣士HP80なら肩入れで剣士が28を受けるか術師が29残る。次戦の断唱のために6Qを温存できる。

## B — TPなし・用途別の戦術札と前後の入力

各周期に各人1手を選ぶ。術ごとに前手／後手が固定。前手→敵の公開順→後手→周期末。同区分は剣士→魔術師→衛士。敵に倒された後手は失効。基本技は無料。強い対応は再生するTPでなく、**雷札または楯札**をその技で消費する。初期は各1枚、上限は各2枚（合計4）。固定キャンプで計2枚を好きな内訳で受取。各上限で切捨て。札アイテムを技以外で転用できず、レシピ・売買・合成なし。キャンプと初期以外は入らない。傷薬と札は別枠、どちらも持越。

| 人物 | 候補と持込例 |
|---|---|
| 剣士／通常候補6から4 | **速刺**前・物理6（撃破圏）、**重断**後・物理16（受け切った後の高打点）、**こじ開け**前・術式4と構え解除（敵防御の解除）、**落雷**前・雷札1で大技を消す／他の攻撃予告−6（外部消耗品）、踏止 前・剣士自身への次の被害−10（自己防御）、追刃 後・物理7、同周期の仕込みがあれば15（連携）。 |
| 魔術師／通常候補5から4 | **閃光**前・術式8、**仕込み**前・術式3＋同周期のみの印、**残光**後・術式5、印があれば12、**退避**前・魔術師自身への次の攻撃−10、散光 後・敵2体へ術式7。印は消費技で消え、未使用でも周期末に消える。 |
| 衛士／通常候補4から3 | **割槍**前・物理4、**庇盾**前・味方への単体攻撃を肩代わりして8軽減、**護札**前・楯札1で自身の肩代わりと14軽減、返し 後・物理12、今周期に生存して被弾済みなら物理15。 |

| 報酬 | 技・代価 |
|---|---|
| X 先駆の穂 | 剣士の落雷を**一閃**に交換。雷札1で前手・物理15。大技の予定を消す能力は「その手番で倒す」ことで代替。 |
| Y 編み楯 | 衛士の護札を**結界**に交換。楯札1で指定味方の次撃−22、対象は同じ。軽減が発生したら、攻撃元の次の攻撃予告を−4（1回のみ、周期を越えても戦闘限り）。衛士に被害を集める機能は失う。 |

同じ保護目標への複数効果は先に予約したもの1件のみ。各候補の持込はキャンプ・報酬間だけに限らず戦間に変更可。速攻は序盤に前手＋後手で敵予定前後の撃破を比べ、中盤で一閃を獲得、終盤は高HPの防御役なら落雷を戻し、補充枠を楯札へ振る選択も取る。継戦は序盤に庇盾、次に結界で低い味方を保護、後半は育った衛士に「返し」を持ち込む。最初と二番目の報酬で、それぞれ剣士・魔術師の残り候補と衛士の返しを解放する想定。

**同じ標準ロードアウトでの4判断。** ①魔術師HP24へ36なら退避で26を受けて倒れる。衛士HP20は護札で引き取っても22で倒れるので雷札を使う。②魔術師HP25／衛士HP24に36、雷札0・楯札1、撃破圏外。護札なら衛士が2残るが、庇盾なら倒れる。③警護のない敵HP13なら速刺6＋閃光8で前手撃破し雷札を温存。④魔術師HP30／衛士HP60の大技36は無料庇盾で衛士32残。次戦に向け両札を温存できる。札1枚単位なので同じ合計2でも各種1と雷2・楯0で防御の幅が異なる。

## C — 戦闘限りの成果点と弱点を抜く行動順

各周期に未行動者から1人ずつ即時指示。最初の2手→敵の公開順→最後の1手→R末。同じ人は周期1回。未行動で生存する人数が2以下なら、最大2人まで敵の前に動ける。持ち越すのはHPと傷薬。各戦で**火勢Hは初期0・上限8**。開始時からいる敵ごとに、最大HPの75%・25%（端数切捨て）以下へ最初に下げたとき各+2。HP回復で解除されず、開始時に既に以下の境界は使用済み。1撃で両方を越すと+4。敵追加・召喚は支給0。初撃時の支払いに後払いの火勢は使えない。敵ごとの境界残数と、どの攻撃で越すかをHPバーに出す。キャンプは傷薬1、火勢を回復するアイテムはなし。

| 人物 | 候補と持込例 |
|---|---|
| 剣士／通常候補6から4 | **斬撃**0H・物理10、**崩し**0H・術式4＋構え解除、**遮断**3H・大技取消／通常の攻撃予告−4、**救援**0H・味方への単体攻撃を剣士へ移し6軽減、楔0H・術式4＋切目（対象への次の味方ダメージ+6、1回・同周期限り）、放散4H・敵2体へ術式12。 |
| 魔術師／通常候補4から3 | **符刃**0H・術式8、**灼弾**0H・術式4＋R末5×2、**火床**0H・その敵の攻撃予告−6、爆裂3H・術式10、切目を消費した場合は16。灼弾の同一対象への再付与は回数2へ上書き。 |
| 衛士／通常候補4から3 | **押槍**0H・物理8、**護衛**0H・味方への単体攻撃を衛士へ移し8軽減、**報復**0H・自身が次に被弾し生存すれば9反撃、固定2H・その敵の構えを解除し次の構え1回を失効させる。 |

予告への保護と状態は現在周期末に失効（灼弾および「固定」で予約した1回の構え失効を除く）。切目の追加は元の命中と一つのHP変化として処理。救援と護衛は先に選んだもののみ。速攻は序盤に崩しと術式で閾値を跨ぎ、中盤で閾走、終盤は楔と爆裂を解放して長い盾戦へ持ち込む。継戦は序盤に護衛や報復、中盤で返照、終盤は火勢2を固定へ渡して低HPの味方に予告が来る時間を減らす（攻撃まで止まる効果はない）。剣士・術師の第4以降の候補は第2・5戦後、衛士の固定は第5戦後を目安に解放。

| 報酬 | 技・代価 |
|---|---|
| X 閾走の刃 | 遮断の代わりに**閾走**3H・物理16を装備。閾値を越せる敵に先に撃つ用途、発動時点で支払い。 |
| Y 照り返しの腕輪 | 遮断の代わりに**返照**2H・味方への単体攻撃を剣士へ移し8軽減、次の敵後の味方攻撃へ攻撃元の切目を作る。剣士が被害を受け生存したときだけ。 |

**同じ標準ロードアウトでの4判断。** ①先の2手では敵HP44を倒せず、魔術師HP23へ36、庇える2人もHP22なので3Hを遮断に使う。②次の手が敵より後の衛士にしか残っておらず、その前の剣士で守る必要がある、魔術師HP30・剣士HP24の同じ予告で遮断。救援は30ダメージで剣士を倒す。③敵HP16なら斬撃10＋符刃8で先に倒し、Hは次の敵へ温存。④盾だけが構える周期は、遮断にHを使わず崩しと符刃。既に消化した閾値は復活しないので、残ったHは次の大技へ回す。

## 操作の負担を抑える

戦闘で表示する技は携行分だけ。射程・資源不足は同じ位置で無効理由を出し、有効な対象を先に強調する。Aは3手の入替・取消と結果差分、Bは同画面の前／敵／後と札内訳、Cは手番境界とHPバーの使用済み閾値を表示する。成長画面は「現在の技を何と交換するか」と「次の敵の構え・予告」を並べる。候補拡張、アイテム、状態を1つの階層メニューに押し込まない。 [数値を追うシナリオ](SCENARIO_WALKTHROUGHS.md)
