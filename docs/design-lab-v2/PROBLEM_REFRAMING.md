# EMBER Design Lab v2 — 何を選ぶゲームか

基点 `c21c5bc4d42ff83602d2f74bd4d5f18c1678eed5`。指示 `365669f0427999df3c564066d4c02d99c8ae043a`。Design Lab v1は問題の観測に参照した。

| 現行の前提 | 判断が固定される理由 | 再設計で確かめること |
|---|---|---|
| 個別TP最大5 | 1回復が上限の20%。集中装備で2→1になると同じ予算で2回使える。通常版のv1試験では84%の手番で満タンだった。 | 細かい支払いを比較する方式と、継戦資源を低頻度の切り札に限定する方式を比べる。 |
| 開始とラウンドごとのTP補充 | 相手を倒す前に余った自然回復を資源化できる。撤廃だけでもv1の長期戦では枯渇が増えた。 | 時間経過で増える持越資源を外す。無償行動には別の代価と独立した用途を持たせる。 |
| 固有技2種と通常攻撃 | 高威力技が同じ対象・同じタイミングの通常攻撃を置換。構え貫通だけを与えると成立しない敵で枠が空く。 | 攻撃、対象の移し替え、割込み、反撃、状態の利用を別の目的にする。3人で敵の予定をどう変えるかを考える。 |
| 固定順と敵の対象予告 | 予告の価値は高いが、共通防御があると予告対象本人の仕事が固定化。HP減少に応じて読みを変える敵も少ない。 | 別の味方で対処するか、相手の手番そのものを移すか、行動順に対価を持たせる。敵の予定変更は公開する。 |
| 数値や確率を動かす装備 | POWERの上昇で撃破圏は変わるが、新しい筋道が見えにくい。v1の護符は操作を増やしても牽制と競合した。 | 持込コマンドの置換で「次に打つ手」や「誰に繋ぐか」を変える。代わりに失う手も見せる。 |
| 敵AIの周期と対象ローテーション | 見やすい反面、盾・大技に先回りできる手の種類が少ない。完全ランダム化は情報の価値を下げる。 | 盾、単体大技、有限回復を同じ敵役に与え、予告を見た後の解決手段を増やす。 |

目標は3人で敵の予告を読み、誰が余力を残し、誰がリスクを負い、何を次戦へ持ち越すかを決めること。将来の1〜2時間ランには報酬で異なる立ち回りが要る。今回は同じ序盤編成と強化された次戦を用い、選択の違いを観測する。ダメージの乱数・命中・クリティカル・全員共通の防御・自動TP回復を試作から外し、予告と行動経済を比較しやすくする。
