# Phase C — 人間レビューに出す候補

設計検証のみ・未採用。次の人手比較は、**タイムライン方式を先に試し、一括方式を対照に残す**。時系列方式は敵の発動時刻と自分の次手を同じ画面で比較でき、印を使い切っても硬直と対処手段の選択が残った。一括方式は相談して三手を組む感覚に価値があり、刻印→追撃に計画を寄せる傾向と、低HP時の立て直し方が論点。即時手番と突破ボーナスはPhase Aの設計候補として保留。

| プレイで確認する問い | 試し方 |
|---|---|
| 時刻を見ることは楽しいか | タイムライン初戦のt0で、破勢、硬直2の追撃、強襲から1つを選ぶ。時刻t3の大技に何が間に合うか、次の2手までを口頭で説明できるかを見る。慣れた後も毎手同じ短手になるなら、硬直差の調整より先に役割の差を検討する。 |
| 3人の順序を組む価値があるか | 一括初戦で刻印と追撃を逆順に置く。庇護・破勢・集中攻撃で、誰が攻撃を引き受けるかまで変わるかを確認する。下書きの手数や確認回数も測る。 |
| 温存か浪費の一択にならないか | 最初の戦闘で印を使う／残す、補給を使う／残すを対で試す。初戦終了と強化戦でHP・次に残したい手を比較。印が余る場合は、新しい回復を足す前に切り札の役割や補給の必要性を見直す。 |
| 報酬で対処が変わるか | 返し槍では敵の攻撃先を衛士へ移すタイミングと、槍撃を失う費用を確認。治療具では緊急回復と庇護を失う費用を確認。返し槍で前に出る先が偏る場合、追加能力よりも置換する技や発動条件を再考する。 |

両方式が同じシードと編成で続けて試せる。プレイ後に「同じ予告へ自分なら他に何をするか」と、その理由を記録する。勝率と行動回数は補助情報として扱う。 [3案と設計時の戦闘例](ALTERNATIVES.md) · [起動と比較結果](PROTOTYPE_REPORT.md)
