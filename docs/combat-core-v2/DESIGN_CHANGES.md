# Combat Core v2 — 相互作用の設計

指示 4caaebc762dcce3919ee4b02ccec3d2827e7a490。基点 49c9f13a697a07b6d2e96c80ad566f389d8731bd。v1は別ディレクトリで再実行できる。 [v1の成長検証](../combat-core-v1/PROGRESSION_REPORT.md)

| 要素 | v1 → v2 | 選択が変わる点 |
|---|---|---|
| 防御 | ボスの儀式防護43%・専用解除 → 構え中の物理半減。護衛は装備した敵の共通特性。 | 物理で構えを崩す、術式で迂回、護衛役を先に撃破、持続ダメージへ回す。破甲は盾兵にも将にも有効。 |
| 敵の予告 | 再詠唱だけ中断無効 → 敵定義に攻撃・詠唱・大技・構え・範囲・回復を並べる。 | 断唱は未実行の詠唱大技を止める。範囲攻撃には減衰と耐衝、単体には庇護・分散・挑発。 |
| 火傷 | 刻み回数を術師に固定 → 付与者・威力・残りを持つ状態。 | 炎弾・火花の迎撃で付与、火継ぎの連斬で延長、爆ぜ火で残量を打点に変換。火渡しは別敵へ写す。 |
| 装備 | 爆ぜ火の所有者専用 → 味方の火傷消費に反応。破勢の印は任意の構えへの破甲に反応。 | 戦闘中に条件を作り、発動した理由を予測と実行の両方に表示する。 |
| 回復 | 応急・魔力転換でHP回復 → 傷薬。元の2枠は耐衝・火渡し。 | 傷薬を戦闘中に使うなら1手を支払い、戦間なら手番不要。支援役は被害・予告・状態の制御を担う。 |
| 成長 | 経路を選ぶと完成済みの持込セットに置換 → 個別報酬・所持・習得・装着・持込を分離。 | 実際にどの枠から何を外すかを確認する。後から混成へ変更できる。 |

火傷は通常6ダメージ×2回、導火の指輪で付けた場合は8×2。周期末に1回。残り総量が大きい方を保持し、同値なら新しい付与者で上書きする。延長の上限2。撃破・戦闘終了で持ち越さない。爆ぜ火の追加は残量そのもの。元の術式打点は通常攻撃より4低くTP8なので、通常攻撃で足りる場合や延長できる場合は維持が有利。手袋は別の生存敵へ最大2回まで写し、別敵がいない場合、消費された生存敵の未弱体攻撃予告を5下げる。反撃は実被害かつ生存時に一度だけ。

傷薬は初期1個、上限3個、+31HP。満タン・戦闘不能に使用不可。通常戦・強敵戦の報酬で各1個を選べる。TP30・開始18・75/50/25%初到達時の生存者+2はv1からの比較基準。敵が回復しても使用済み閾値は戻らない。 [データ](../../combat_core_v2/content.json)

技は各人6候補・持込4と通常攻撃。連斬・爆ぜ火・迎撃・応急・魔力転換の変更は上記。破甲の再構え抑止、断唱、挑発、返し刃、連携撃、火印、炎弾、火炎波、減衰、槍撃、庇護、分散、結束は各役割を維持し、状態や敵IDを参照する効果を共通ルールに置いた。R1の状態変更や既に弱体済みの予告は1回の対象として扱う。
