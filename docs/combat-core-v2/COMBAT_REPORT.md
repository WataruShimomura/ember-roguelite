# 汎用ルールと固定局面の反証

| ケース | 観測 |
|---|---|
| T1 構え | 盾兵にも灰冠の将にも同じ破甲と破勢の印で再構え抑止が発動。構えのない詠唱士では通常攻撃13・破甲8で、通常のほうがTPも消費しない。物理護衛は敵IDと無関係に構え＋護衛特性を参照する。 |
| T2 キャラ横断 | 炎弾の術師由来の火傷が周期末で残り1に。剣士が火継ぎの連斬を選ぶと残り2になり、付与者は術師のまま。別枝では衛士が火花の迎撃で詠唱士に火傷を付け、術師が爆ぜ火で残り1×6を消費。手袋ありでは他の生存敵にも写り、なしでは写らない。 |
| T3 維持と消費 | HP83の詠唱士では通常攻撃と火傷維持でTPを温存し、さらに1回を残した。HP19で残り2回なら通常攻撃12は致死に届かず、爆ぜ火の8+12で敵の攻撃前に撃破。衛士の実被害にも差が出た。 |
| T4 回復と悪用 | 初期HP33の術師に、即撃破後の戦間傷薬または3周期待機中の傷薬を使うと、どちらも64・在庫0。即撃破を迂回した方では剣士のTPが18→9。敵の自己回復後に同じHP帯を削っても閾値TPの再支給なし。 |
| T5 個別報酬 | 傷薬を選ぶと次戦前に術師33→64へ回復可能。指輪は取得後に装着して火印が威力8の火傷を付与。迎撃は取得後に1枠交換して、衛士の被弾を次の術師・剣士の連携へ変える。2回目の取得で既存装備や技は一式置換されなかった。 |
| T6 非専用鍵 | 強打と範囲はパターンに記述。効果側に将専用の攻撃・解除処理はない。火傷付与を除外した入力でのボス直行を別に計測。 [結果](PROGRESSION_REPORT.md) |

F1のTP0でも、39の単体予告は減衰で30、分散で15ずつ。HP22の術師が7で残る。火傷を持ち込まなくても予告を読む意味があり、支援行動の代わりに攻撃をして撃破が間に合うなら資源を残せる。F5・F6の長期・装備差と成長4条件は別集計。 [比較データ](metrics.json)

装備の上位互換を確認するため、残り火傷・消費者・装着の有無を同じ入力から分岐した。手袋は伝播先がなければ予告を弱める。最終版は詠唱士単体の同じ火傷を爆ぜ火で消費し、手袋ありの予告23に対して、なしでは28。既に弱体済み、回復、構え、撃破の場合は追加の軽減がない。火印は単独の打点では炎弾より低い。返礼の鎧は庇護で実被害を受けるまで効果がなく、次の迎撃にも敵の攻撃が必要。 [未解決点](OPEN_ISSUES.md)
