# 3戦の成長と難度

閾値TPあり、シード42〜51。速攻・有限回復/継戦・防御/反撃・状態利用・温存・状況判断の6方針を同じ敵・初期条件に適用。遅延・合法ランダムは反証用として別に集計した。U0/U1は同じ構成を経路ごとに重複計上しない。U2/U3は5つの個別報酬経路を各60件。以下は連戦の勝率で、ボス直行とは分けた。 [機械集計](metrics.json)

火傷を使えないようにした独立したボス直行は、Lv3・満タン・TP18、同じ10シードと速攻・状況判断・反撃の3方針で28/30。狙いは「火傷がないと解除できない」条件の反証。直行は3戦を通る試合と資源条件が異なる。

## 資源収支

U3主比較300ランで、傷薬は戦闘中397回、戦間139回使用。標準は初期1個＋報酬2個の最大3個、攻撃・混合は初期1個で進む。回復品を取らない選択は無償回復が付かない。一方、閾値供給OFFの960連戦は全敗し、U3のボスの通常攻撃率が47.4%→88.9%。F5の長期負荷でも通常技寄りになった。火炎波で3体の未通過閾値を同時に踏むと、本人10消費に対して各人6獲得（計18）。範囲攻撃による短い局面の供給集中はRISK。次のレビューでは供給各2の維持と、1行動に出る総量の制限を比較する余地がある。

旧v1の主比較はU0 0/60・U1 17/60・U2 0/180・U3 139/180。別ルール・別経路なので優劣の直接比較には使っていない。v2内の比較では、無成長の楽勝は再発せず、数値と戦術を合わせた場合に差がある。 [注意点](OPEN_ISSUES.md)
